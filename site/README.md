# Сайт услуг для ЖКХ

Одностраничный сайт `index.html`: услуги для УК и ТСЖ (трекер текущего ремонта, веб-приложение на Google Таблице, встраивание в Битрикс24, сверка Excel, отчёты, сопровождение), кейс, порядок работы, вопросы и форма заявки.

## Перед публикацией

1. В конце `index.html` замените значения в объекте `CONTACT` (имя, телефон, e-mail, Telegram) — они подставятся по всей странице.
2. При желании поправьте цифры кейса и тексты услуг.

## Как опубликовать

Это один статичный файл, сборка не нужна. Подойдёт GitHub Pages, Netlify, Tilda (блок HTML) или любой хостинг: загрузите `index.html` в корень.

Форма заявки ничего не отправляет на сервер: она собирает текст заявки, который посетитель копирует или отправляет в Telegram / письмом. Чтобы заявки приходили автоматически, подключите обработчик (например, Google Apps Script или бота Telegram) в обработчике `submit`.
