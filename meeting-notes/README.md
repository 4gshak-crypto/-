# Протокол совещания: транскрибация и саммари

Локальное приложение: загружаете запись совещания, получаете расшифровку и протокол с решениями, поручениями и открытыми вопросами. Выгрузка в Word, Markdown, TXT и SRT.

- **Распознавание речи** идёт на вашем компьютере моделью Whisper (библиотека faster-whisper). Запись никуда не отправляется.
- **Протокол** составляет Claude (модель `claude-opus-5-5`) по тексту расшифровки. В Claude API уходит только текст.

## Что получается

| Файл | Содержимое |
|---|---|
| `protocol.docx` | Протокол в Word: кратко, темы, решения, таблица поручений, открытые вопросы, в приложении расшифровка |
| `summary.md` | То же в Markdown |
| `summary.json` | Протокол в машиночитаемом виде (для Битрикса, таблиц, трекера) |
| `transcript.txt` | Расшифровка с таймкодами |
| `transcript.srt` | Субтитры, можно открыть вместе с видео |
| `transcript.json` | Фрагменты с временем начала и конца |

Поручения в протоколе содержат задачу, ответственного и срок. Если ответственный или срок на совещании не прозвучали, в протоколе будет «не назначен» и «не назван»: Claude не придумывает их.

## Установка

Нужен Python 3.10 или новее.

```bash
cd meeting-notes
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # впишите ANTHROPIC_API_KEY
```

При первом запуске faster-whisper скачает модель (medium занимает около 1,5 ГБ) с Hugging Face. Для видеокарты NVIDIA нужны CUDA 12 и cuDNN 9; без них всё работает на процессоре.

## Запуск

```bash
python -m meeting_notes
```

Откройте http://127.0.0.1:8787. Перетащите запись (mp3, m4a, wav, mp4, mkv и другие форматы FFmpeg) или готовую расшифровку (.txt, .srt, .vtt), при желании укажите название, дату и подсказку: участников, повестку, правильное написание фамилий и адресов. Подсказка попадает в запрос Claude и заметно улучшает имена и термины в протоколе.

Задачи выполняются по очереди в фоне. Страницу можно закрывать: результаты остаются в папке `data/jobs/` и в истории слева.

### Командная строка

```bash
python -m meeting_notes.cli запись.mp3 --title "Планёрка по ремонту" --date 07.10.2026
python -m meeting_notes.cli запись.mp4 --no-summary        # только расшифровка
python -m meeting_notes.cli расшифровка.txt --out протокол  # протокол по готовому тексту
```

## Скорость и качество

Время расшифровки на обычном процессоре (4–8 ядер), на часовую запись:

| Модель Whisper | Время | Качество русского |
|---|---|---|
| `small` | 5–10 мин | приемлемо, ошибается в фамилиях и терминах |
| `medium` (по умолчанию) | 15–30 мин | хорошо |
| `large-v3` | 30–60 мин | лучшее; на видеокарте 2–4 мин |

Модель задаётся переменной `WHISPER_MODEL` в `.env`. Протокол Claude готовит около минуты.

Разделения по говорящим нет: Whisper не определяет, кто говорит. Если это важно, назовите участников в подсказке, и Claude по контексту укажет их в решениях и поручениях.

## Безопасность

- Сервер слушает только `127.0.0.1`. Чтобы открыть доступ коллегам в локальной сети, задайте `MEETING_HOST=0.0.0.0`, но помните, что авторизации в приложении нет: защищайте доступ средствами сети.
- Если запрос отклонит классификатор безопасности Claude, API автоматически повторит его на запасной модели (параметр `fallbacks="default"`), и протокол всё равно будет составлен.
- Ключ API хранится только в `.env`, который не попадает в git.

## Структура

```
meeting_notes/
  server.py      веб-сервер и очередь задач (FastAPI)
  pipeline.py    запись → расшифровка → протокол → файлы
  transcribe.py  faster-whisper, разбор .srt/.vtt/.txt
  summarize.py   запрос к Claude со структурированным ответом
  export.py      Markdown и Word
  cli.py         командная строка
  static/index.html  интерфейс
tests/           проверки без сети и без моделей
```

Проверки: `python -m pytest tests`.
