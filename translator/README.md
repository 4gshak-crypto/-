# Татарча тәрҗемәче — переводчик с татарского языка

Одностраничный переводчик татарский ↔ русский (и английский) без установки и ключей API.

- `index.html` — вся страница: откройте файл в браузере, и переводчик работает.
- `Code.gs`, `appsscript.json` — вариант на Google Apps Script, если нужен постоянный адрес (например, для встраивания в Битрикс24).

## Что умеет

- Перевод с татарского на русский и обратно, а также на английский; язык исходника можно определять автоматически (по буквам ә ө ү җ ң һ и встроенному словарю).
- Перевод по мере ввода или по кнопке «Перевести».
- Татарская клавиатура: кнопки ә ө ү җ ң һ под полем ввода и сочетания Alt+а, Alt+о, Alt+у, Alt+ж, Alt+н, Alt+х (работают и с латинскими a, o, u, j, n, h).
- Разбор по словам: слова из встроенного татарско-русского словаря (около 400 самых частых слов и выражений) показываются с переводом под текстом.
- Латиница: татарский текст дублируется в латинской графике (упрощённый заманәлиф).
- Разговорник с готовыми фразами, история переводов в этом браузере, копирование и озвучивание русского перевода.

## Какой перевод используется

Страница сама выбирает доступный способ, в этом порядке:

| Где открыта | Кто переводит |
|---|---|
| Опубликованный артефакт Claude | Claude (по кнопке; при первом запросе страница просит разрешение, запросы расходуют лимит того, кто открыл страницу) |
| Веб-приложение Apps Script | Google Переводчик через `LanguageApp` на сервере |
| Файл `index.html`, открытый напрямую | Открытый эндпоинт Google Переводчика, при сбое — MyMemory |
| Сеть недоступна | Пословный перевод по встроенному словарю, с пометкой |

## Установка на Google Apps Script (около 5 минут)

1. Откройте [script.google.com](https://script.google.com) → **Новый проект**.
2. Замените содержимое `Code.gs` на файл `Code.gs` отсюда.
3. **+ → HTML**, назовите `Index`, вставьте содержимое `index.html`.
4. **Настройки проекта → Показывать файл манифеста appsscript.json** и замените его на `appsscript.json`.
5. **Начать развёртывание → Новое развёртывание → Веб-приложение**, «Запуск от имени»: Я, «У кого есть доступ»: Все. Скопируйте ссылку `…/exec`.

Ссылку можно встроить в Битрикс24 так же, как трекер (см. `gas/README.md`).
