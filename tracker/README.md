# Трекер текущего ремонта

Живой трекер работ текущего ремонта (сентябрь–декабрь 2026) по годовому плану.

- `data.json` — работы из листа «2026» годового плана (номера строк, адрес, УК, основание, оценка, статус и исполнитель по цвету заливки), отметки капремонта и открытые вопросы.
- `template.html` — страница трекера.
- `build.py` — собирает `index.html`: `python3 build.py`.

Опубликованная версия хранит отметки команды (статус, исполнитель, комментарии, закрытые вопросы, добавленные работы) в общей базе артефакта поверх плана из файла.
